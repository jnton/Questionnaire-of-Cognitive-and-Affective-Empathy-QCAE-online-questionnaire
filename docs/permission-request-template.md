# Permission request template

Subject: Permission to publish a privacy-first online QCAE implementation

Dear QCAE rights holder,

I maintain a free, privacy-first online implementation of the Questionnaire of Cognitive and Affective Empathy. The application performs all scoring locally in the user's browser, stores no responses, contains no advertising or analytics, and cites the original publication.

I am requesting written permission to:

- display and administer the QCAE online;
- reproduce all item and response wording in a public source repository;
- publish a machine-readable JSON representation for research software and accessibility tools;
- include sourced French, Portuguese, Serbian, and German translations where permitted; and
- allow users to download their own raw scores and responses.

The software code is AGPL-3.0-only, while the questionnaire content would remain attributed and governed by whatever conditions you specify. I will not claim that the software licence applies to the QCAE wording.

Please state any required attribution, use restrictions, translation conditions, or licence language.
