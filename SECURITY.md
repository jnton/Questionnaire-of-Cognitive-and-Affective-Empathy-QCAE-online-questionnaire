# Security policy

## Supported version
Only the latest `main` branch is supported.

## Reporting
Please report security or privacy issues privately to the repository owner rather than including participant data in a public issue.

## Security model
The production application is static, has no backend, no user accounts, no third-party JavaScript, and no response persistence. The principal risks are supply-chain changes, accidental introduction of telemetry, scoring regressions, content tampering, and misleading interpretation of results.
