Rights and AI use

AI use and text-and-data mining are welcome

This project makes no text-and-data-mining reservation. Research and commercial or non-commercial AI use are expressly welcomed under the terms applicable to each resource.

Project licences

Original application code is licensed under AGPL-3.0-only. Project-created documentation, metadata, schemas, UI copy, and synthetic examples are dedicated under CC0-1.0.

Sources and attribution

Questionnaire versions are linked to their published sources and validation records. Applicable source terms and attribution requirements continue to apply. The repository imposes no additional project-specific restriction and makes no TDM reservation.

No response processing by this deployment

The public site has no response-submission endpoint. It does not receive, store, transmit, analyse, or otherwise process questionnaire responses on a server. Browser responses remain in browser memory, while API and command-line response objects remain in the calling software or agent environment.

Machine-readable declaration

The canonical declaration is data/ai-use-policy.v1.json. HTML pages use tdm-reservation=0.

Language-specific sources and validation publications are listed in the reference registry.
