Programmatic access

Agents and developers

Agents may administer, score, analyse, export, index, and use the project for AI/TDM workflows without submitting questionnaire responses to this site.

Discovery

data/capabilities.v1.json — versioned operation and endpoint manifest

data/ai-use-policy.v1.json — explicit AI/TDM permission and scope

data/qcae.v1.json + data/locale-packs.v1.json — base instrument and validated locale packs

data/references.v1.json + data/reference-packs.v1.json — papers and provenance

llms.txt and llms-full.txt — concise and expanded guidance

Browser or JavaScript scoring

import { loadInstrument, scoreResponseDocument } from
  "https://jnton.github.io/Questionnaire-of-Cognitive-and-Affective-Empathy-QCAE-online-questionnaire/src/qcae-api.js";

const instrument = await loadInstrument();
const result = scoreResponseDocument(instrument, {
  locale: "ru",
  responses: { "2": 3, "3": 4 /* ... all active items ... */ }
});

loadInstrument() automatically merges all published locale packs. It performs no telemetry or persistence.

Command line

node bin/qcae-score.mjs --list-variants
node bin/qcae-score.mjs examples/responses.en.synthetic.json
cat responses.json | node bin/qcae-score.mjs --locale ko -

Browser automation

Select a locale with ?lang=en, ?lang=fr, ?lang=pt-PT, ?lang=de, ?lang=sr-Latn, ?lang=tr, ?lang=ru, or ?lang=ko. The semantic form exposes stable data-qcae-* attributes and a read-only window.QCAE_APP object.

Response datasets

The site does not currently receive responses. Implementers who add an optional donation endpoint should use the separate machine-readable consent template, collect only the minimum data, and attach a dataset-specific permission marker.

Permission

The project supplies open web files, JSON, JSON Schema, ES modules, a CLI, semantic HTML, explicit capability metadata, and tdm-reservation=0. AI use is expressly welcomed within the AI-use policy.
