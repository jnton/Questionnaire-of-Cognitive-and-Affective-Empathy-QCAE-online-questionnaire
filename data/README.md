# Data resources

The complete runtime instrument is assembled from `qcae.v1.json` and `locale-packs.v1.json`. The complete reference registry is assembled from `references.v1.json` and `reference-packs.v1.json`.

AI/TDM permission is declared in `ai-use-policy.v1.json`. The public site does not collect responses; `response-donation-consent.v1.json` is a template for a future separate opt-in flow.
